HR Analytics Project

Project Overview

This project focuses on analyzing employee data to understand workforce trends, employee attrition, salary distribution and department-wise performance.

Tools Used

* Microsoft Excel
* SQL
* DB Fiddle

Project Activities

* Employee data analysis
* HR metrics calculation
* Attrition rate analysis
* Average salary calculation
* Department-wise employee analysis
* HR Dashboard creation using charts
* SQL queries for data analysis

Key HR Metrics

* Total Employees
* Active Employees
* Employees Left
* Attrition Rate
* Average Salary
* Average Age

SQL Concepts Used

* SELECT
* WHERE
* COUNT
* AVG
* MAX
* GROUP BY
* ORDER BY
* CASE WHEN

Objective

To understand employee trends and provide useful insights that can support HR decision-making.
